# נתוני גלישה ומפות חום (8.10.2026)

**כלים:** Cloudflare Web Analytics (מבקרים, דפים, מדינות, מכשירים, מהירות; בלי עוגיות) ו-Microsoft Clarity (מפות חום, גלילה, הקלטות; פרויקט נפרד "לאוקמי גירסא", עוגיות כבויות).
**בעלים:** חשבון הגוגל וחשבון Cloudflare של המנהל. לא צורף אדם נוסף.

## איך זה מוטמע
- שורת `script` אחת (`/lk-core.js`, defer) מוזרקת לכל דף בסוף כל בנייה על ידי `tools/lk_inject.py` (נקרא מ-`build_all.py`). אין שינוי בתבניות.
- ההגדרות (מזהה Clarity, אסימון Cloudflare) ב-`tools/lk/config.json`. מזהה Clarity ריק = Clarity כבוי.
- Cloudflare: הדומיין ב-DNS בלבד (בלי Proxy), ולכן ה-beacon נטען מהסקריפט, פעם אחת, במצב `spa` (כל שינוי כתובת או `#p=` נרשם כצפייה).
- אין CSP באתר, ולכן לא נדרש שינוי. הדומיינים: `static.cloudflareinsights.com`, `cloudflareinsights.com`, `www.clarity.ms`, `*.clarity.ms`.

## החרגות (נבדקו בדפדפן)
1. **מכשיר מנהל** (יש בו `lg-adm` או `lg-admin`): אף כלי אינו נטען, בשום דף. כך ביקורי המנהל אינם מעוותים את מפות החום. ב-Cloudflare Web Analytics אי אפשר להחריג מנהל בלי הסקריפט, ולכן המנהל פשוט אינו טוען אותו.
2. **כל מצב עריכה** (גוף הדף מקבל `ed`, גם אצל מציע שאינו מנהל): `clarity('stop')` מיד, והוא אינו מופעל שוב באותו דף. מה שנקלט לפני הכניסה לעריכה בדף אינו נמחק.
3. **מצב העיפרון**: רק מנהל, ולכן אינו נטען בכלל.
4. מסכי המנהל (תור ההצעות, תמונת הלומדים, הערות המנהל): נפתחים רק במכשיר מנהל, ולכן מוחרגים מעצם ההגדרה.
5. מצב ההסתרה ב-Clarity: כל `input`, `textarea`, `select` ושדה עריך מסומנים `data-clarity-mask="true"` בעת הטעינה ובכל מיקוד. בלוח Clarity עצמו יש להגדיר Masking לפחות Balanced.

## תגיות ואירועים ב-Clarity
**תגיות לכל צפייה:** `סוג_דף` (בית, מפת הש"ס, רשימת מסכתות, הדף היומי, המקום שלי, בחן את עצמך, שיעורים, אודות, הגדרות, סיום מסכת, מקורות, דף גמרא, דף גמרא סטטי), `page_type`, `מסכת`, `דף`, `מצב_תצוגה` (טורים / טור אחד / מסך מפוצל), `התקן` (טלפון / מחשב). בעקבות כל מעבר דף (`hashchange` או `pushState`) התגיות נקבעות מחדש, כך שמפת חום אחת מצטברת לכל סוג דף.
**אירועים:** מקור, צורת הדף, הצע תיקון, בחן את עצמך, המקום שלי, הדפסה, שיעור יוטיוב, דף הבא, דף קודם, הדף היומי, ניווט. הרשימה והבוררים ב-`EVENTS` בראש הקטע "אירועים" ב-`tools/lk/lk-core.js`.

## מהירות
הסקריפטים נטענים אסינכרונית. על דף גמרא אין סריקת DOM כלל כשאין שינויי טקסט, ובמצב עריכה הצופה נעצר. ראו הדוח לנתוני המדידה.

## לוח נתוני הגלישה (9.10.2026)
הכפתור "נתוני גלישה" בתפריט המנהל פותח את `/admin-stats.html`: העתקה של לוח הסטטיסטיקות של ממלכת הזוהר (אותם מדורים, אותו סדר, אותם ניסוחים בעברית, ללא מדור הגנת התוכן שאין לו מקבילה באתר הזה).
- הספירה: `lk-core.js` סעיף ג. צפייה אנונימית נשלחת ל-`/stats/hit` ב-Worker (`text/plain` כדי לא לגרור בקשת הרשאה מוקדמת). מנהל, מצב עריכה ודפי המנהל אינם נספרים.
- האחסון: D1 בשם `leokmei-stats` (קישור `LSTATS`), טבלאות `zs_c` ו-`zs_s`, נוצרות לבד בקריאה הראשונה. הלוח מתחיל מ-9.10.2026.
- הקריאה: `/stats/summary`, מנהל בלבד (`x-admin-key`, אותו אסימון מכשיר של שאר המסכים).
- לא שונו: מזהה Clarity, מזהה Web Analytics, תנאי ההחרגה, התגיות והאירועים. הלוחות הגולמיים נשארים ב-Cloudflare וב-Clarity ואינם נפתחים מהכפתור.
