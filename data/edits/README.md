# תיקונים שנעשו באתר

כל קובץ כאן הוא `<מסכת>.json`, והוא נכתב **מן הדפדפן** במצב עריכה,
דרך ממשק גיטהאב. אין לערוך אותו ביד.

מה קורה לו:

א. דחיפה לתיקייה הזאת מפעילה את `edits.yml` - בנייה קצרה של המסכת
   שהשתנתה בלבד, והפרסום. הבנייה מחילה את התיקונים על נתוני הדף,
   ולכן כל לומד רואה אותם, וגם ההדפסה והחיפוש.

ב. `tools/ingest_repo.py` רץ במחשב של בעל הפרויקט כל עשר דקות,
   ומכניס את אותם תיקונים לקובץ הוורד שבדרייב - במעקב-אחר-שינויים,
   עם גיבוי ועם אימות, דרך `word_apply.py` בלבד.

ג. כשהנוסח החדש כבר נמצא בקובץ הוורד, הבנייה מוציאה את התיקון
   מן הקובץ הזה. קובץ ריק פירושו שהכול נקלט.

תיקון שאיבד את עוגנו (הפסקה שונתה בוורד) **אינו נמחק ואינו מוחל**:
הוא נשאר כאן ומדווח בלוח הבקרה של המסכת כ"תלוש". הוורד גובר תמיד.
