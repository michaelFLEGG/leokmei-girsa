# הכותב היומי - "הדף היומי בווטסאפ" (8.11.2026)

משימה מתוזמנת בענן (שגרת Claude Code, "כותב הדף היומי - לאוקמי"), פעם ביום ב-15:20 שעון ישראל. המחשב יכול להיות כבוי. היא כותבת תוכן בדוק לדפים הקרובים שחסר להם, כדי שהודעת הבוקר תצא. בלי תוכן בדוק - אין שליחה (השרת אינו שולח "בהכנה").

## הנוהל (בסדר הזה, בלי לדלג)

א. **נעילה ומשיכה.** `git pull origin main`. אם קיים `.locks/daf-wa-writer.lock` צעיר משלוש שעות - סיים בלי לעשות דבר. אחרת כתוב אותו (שם העמדה "ענן" והשעה).

ב. **מה חסר.** `python tools/daf_wa/writer.py need 10` - רשימת הדפים של עשרת הימים הקרובים (ועוד שלושה למרווח) שאין להם תוכן עם `check.ok`. לכל אחד נכתבה הגמרא בלי ניקוד, ממוספרת בשורות, ל-`_work/daf_src/`. אם הרשימה ריקה - שחרר את הנעילה וסיים.
   כתוב לכל היותר שישה דפים בריצה, הקרובים בתאריך תחילה.

ג. **הכרעות המנהל.** קרא `GET https://leokmei-daf.m7654301.workers.dev/learn`. כל רשומה היא עריכה, בחירת "הידעת", עצירה או אישור שבעל הפרויקט עשה בלוח. למד מהן את טעמו (איזה סוג "הידעת" הוא בוחר, מה הוא מקצר, מה הוא מוחק) והחל אותו על הדפים החדשים. אם הכתובת אינה נגישה - כתוב זאת ביומן הריצה והמשך (התוכן אינו נשלח בלי בדיקה ממילא).

ד. **כתיבה.** לכל דף - `data/daf-wa/<slug>-<n>.json`, בדיוק במבנה של `data/daf-wa/bekhorot-32.json` (דוגמאות נוספות: bekhorot-51 עד 61, arakhin-2 עד 4):
   - `hook`: שאלת "הידעת?" אחת, קצרה (עד כחמש עשרה מילים), שמושכת לקרוא - מעשה, פלא, משפט חז"ל או חידוש הלכתי. `kind` אחד מארבעה אלה. `ans` = אינדקס השורה (מ-0) שעונה עליה.
   - `alts`: שתי שאלות חלופיות באותו מבנה, מסוגים אחרים.
   - `card`: כותרת שמגדירה את הדף ומסכמת אותו (עד כשש מילים) - הנושא העיקרי או שניים, כמו כותרת פרק: "חלק הבכור - לא בשבח ולא בראוי". **לא** עניין צדדי שהוזכר בדרך אגב ולא פיתיון (הכרעת בעל הפרויקט, 8.11.2026). היא מופיעה בכרטיס מתחת לשם הדף ובתצוגה המקדימה של הקישור.
   - `lines`: ארבע עד שש שורות, לפי סדר הדף. כל שורה טענה אחת או שתיים, מובנת לבעל בית, ובסופה `ref` - עמוד ומספרי השורות בקובץ המקור ("נא. 7, 9" / "נב: 1-2" / "נא: 12 · נב. 2").
   - מן הגמרא בלבד: `data/sources/<slug>.json`. בלי אתרים חיצוניים, בלי פירושים שאינם בדף, בלי פסיקה מעשית. הסבר קצר למילה קשה - בסוגריים מרובעים [ ]. ציטוט ארמי - במירכאות, עם תרגום בסוגריים כשאינו ברור.
   - בלי מקף ארוך או בינוני. מפריד - " - ".
   - לעולם לא נקודה-פסיק (;) - רק נקודה (הכרעת בעל הפרויקט, 9.11.2026). השער פוסל.
   - ציטוט (פסוק, לשון הגמרא) - בגרש לפני ואחרי ('כך'), לא במרכאות כפולות. גרשיים נשארים רק בראשי תיבות (חז"ל). (9.11.2026)
   - פסוק שמצוטט בשורות 'הדף בקצרה' - מנוקד כלשון המקרא (מן המקרא עצמו, לא מן הזיכרון). לשון הגמרא אינה מנוקדת, וגם לא החידה והכותרת. (9.11.2026)
   - בלי ניקוד.
   - נושאים שאינם הולמים הודעת בוקר לקהל רחב (עריות, זנות) - לא לבחור אותם, יש בדף מספיק אחרים.
   - `check`: `{"ok": false, "by": "", "at": ""}` עד הבודק.
   - בדף האחרון של מסכת - שורת סיום ("הדרן עלך ... וסליקא לה מסכת ..."), בלשון הגמרא בלבד.

ה. **בודק נפרד.** הפעל סוכן משנה בהקשר נקי (לא אתה), **בחזית ולא ברקע** - המתן לתשובתו באותו תור, ואל תסיים תור לפני שחזר עם ההוראות `_work/daf_wa_checker.md` ועם רשימת הקבצים וקובצי `_work/daf_src`. הוא כותב `_work/daf_chk/<slug>-<n>.json`. תקן כל ממצא מוצדק (ממצא שגוי - רשום ב-`why` של הקובץ שלו מדוע נדחה). דף עם ממצא חמור שלא תוקן - אינו מסומן.

ו. **סימון.** רק אחרי הבודק והתיקון: `check = {"ok": true, "by": "בודק נפרד (סוכן ענן)<, אחרי תיקון ...>", "at": "<YYYY-MM-DD>"}`.

ז. **שער.** `python tools/daf_wa/writer.py gate` - חייב לעבור (קוד 0). כשל - תקן, ואם אינו ניתן לתיקון: הוצא את הדף (ok=false) ופרט ביומן.

ח. **דחיפה.** `git add data/daf-wa/*.json _work/daf_chk && git commit -m "הכותב היומי: <הדפים>"`, מחק את הנעילה, `git push origin HEAD:main` (במשיכה וניסיון חוזר עד שלוש פעמים). הדחיפה מפעילה את הבנייה (watch.yml), שמציירת את הכרטיסים החסרים ומפרסמת את האתר. אין צורך לצייר כרטיסים בענן.

ט. **יומן.** שורה אחת ל-`docs/הדף-היומי-יומן-כותב.md`: תאריך, אילו דפים נכתבו, כמה ממצאים מצא הבודק, מה נדחה. (נכלל באותה דחיפה.)
