# מסכת arakhin - לקחים מזוקקים (פרומפט 70)

- ערכין דלה, וההשלמות בה מתקבלות: {הס:} בהגדרות, בחשבונות (חומש, פרוטה, "מעת לעת"), במונחים סתומים, ב"כשיטתו" שאינו אומר מה השיטה, וכשלא ברור מי הדובר. גמרא חסרה כשתירוץ עומד בלי הקושיה או הדובר שמשנים את המהלך. הסבר שהתארך - לנסח את השורה מחדש בלי סוגריים. אבל שורה קצרה ומובנת אינה נבנית מחדש סביב הסבר - רק ארמית ללשון הקודש.
- שמות מתחלפים בערכין - השם המלא: ראב"י (יז = ר' אליעזר בן יעקב, יח = רב אחא בר יעקב), ר"ג יח: = רב גידל, ר"ח יח. = רב חסדא, ר"א גם ר' אבהו (כח:), ר"ש גם רב ששת, ר"י = ר' יוסי / ר' יהודה / רב יהודה, "רבינא לר"א" = לרב אשי, "ור"ה בן ת"ח" = רב הונא בנו.
