# כלי ההמרה החד פעמית של ברכות (פרומפט 38, 15.11.2026)

שמורים לעיון ולשימוש חוזר במסכתות הבאות (שבת, סוכה, בכורות, בבא בתרא). הנתיבים בהם הם של סשן הענן (`/tmp/claude-0/...`) ויש להתאים.

סדר ההרצה:
א. `views.py berakhot admin <docx> v_admin.pkl` ו-`views.py berakhot word <docx> v_word.pkl` - "מה שהמנהל רואה" (הוורד ועוד כל השכבה, מ-`/live`) ו"הוורד לבדו".
ב. `convert.py` - ניקוי הכפילויות (תיקונים מפורשים לפי כוונת העריכות שלא נקלטו, ואחריהם כללים כלליים ר1-ר4), צורה קנונית, ורשימת יעד לכל עמוד.
ג. `dosync.py` - `word_apply.sync_to_target` עם `convert_patch.py` (סגנונות ברכות, השוואה גם לפי העיצוב, סימני מבנה בתוך ההשוואה). אם המעבר האחד נכשל בבדיקת הגבולות - עמוד אחר עמוד.
ד. `gate.py <docx החדש>` - השער: הבנייה מן הוורד לבדו זהה ליעד (בלי הבדלים שאין להם ביטוי בדף), ואין פסקאות צמודות כפולות.
ה. `classify.py` - אילו עריכות הוחלו / כבר בוורד / תלושות; התלושות נבדקות על הוורד החדש, וכל מה שהיה משנה את הדף עובר לארכיון.
