# הדומיין leokmei.com ושיעורי יוטיוב (מנה 4, 7.10.2026)

## הכתובת הקנונית
- הכתובת היחידה: https://leokmei.com (בלי www). www והכתובת הישנה (github.io, כולל דפים עמוקים) מפנות אליה בהפניה קבועה, ברמת GitHub.
- DNS ב-Cloudflare (חשבון המשתמש): ארבע רשומות A וארבע AAAA של GitHub Pages, CNAME ל-www, ורשומת TXT לאימות Google Search Console. הכול במצב "DNS בלבד" (ענן אפור), כדי שתעודת האבטחה של GitHub תתחדש.
- הגשר (tools/gesher.py): מקבל את leokmei.com, www.leokmei.com והישן; SITE מצביע על leokmei.com. אחרי כל שינוי בעותק שבמאגר יש לעדכן גם את העותק הרץ בתיקיית leokmei-gesher במחשב ולהפעילו מחדש.
- tools/build_seo.py (רץ בסוף build_all): קנוני, תיאור, תגי שיתוף, נתונים מובנים, sitemap.xml, robots.txt, CNAME, ודף אודות. דפי עבודה מסומנים noindex.
- אחסון הדפדפן שייך לכתובת, ולא עובר מהכתובת הישנה (היא מפנה ברמת השרת). מנהל מתחבר מחדש עם המפתח. לומד שרוצה את ההיסטוריה שלו מעביר אותה בקוד סנכרון (/ln/code ו-/ln/redeem) מהמכשיר שבו היא שמורה, אם עוד נגיש.

## שיעורי יוטיוב
- שרת: leokmei-suggest, נקודה /lessons. קריאה פתוחה (GET); הוספה ומחיקה למנהל בלבד (POST, כותרת x-admin-key, op=add או del). הכותרת והתמונה נשלפות מ-oEmbed של יוטיוב.
- ממשק: tools/lamed/shiurim.js. מדור "שיעורים" (shiurim.html), כפתור זהוב "שיעור על הדף" בדף הגמרא כשיש שיעור לדף הנוכחי, נגן youtube-nocookie בלחיצה. צפייה נרשמת כלימוד (אירוע dn עם how=shiur) לכל הדפים שהשיעור מכסה.
- נתונים מובנים VideoObject: בדף השיעורים (בצד הלקוח) וגם סטטי בבנייה (build_seo קורא את /lessons).

## נוהל הוספת שיעור (למנהל)
א. פתח את leokmei.com/shiurim.html כשאתה מחובר כמנהל.
ב. הדבק קישור יוטיוב, בחר מסכת ודף (ואם יש טווח, גם עד דף).
ג. לחץ "שמור". הכותרת והתמונה מתמלאות לבד.

## פתוח לעתיד
- ייבוא אוטומטי מערוץ או רשימת השמעה: נדרש קישור מהמשתמש. התשתית (/lessons עם op=add) קיימת.
- כתובת סטטית לכל דף גמרא (כיום כתובת לכל מסכת; הדף נבחר בחלק # שגוגל אינו מאנדקס).
- Bing Webmaster: ייבוא מ-Search Console, ובקשות סריקה ידניות לדפים מרכזיים.
