# לאוקמי גירסא - שלושת המנועים

## התקנה
```
pip install lxml --break-system-packages
```
זה הכל. אין תלות אחרת.

## הרצה על מסכת חדשה

```
python3 laukmi_scan.py        <מסכת.docx> out        # דוח מצב, לא נוגע בכלום
python3 masechet_1_mechani.py <מסכת.docx> שלב1.docx  # המנוע המכני
python3 masechet_2_otzva.py   שלב1.docx              # הפקת האצוות
   ... הכרעה על citations.json ו-aramaic_todo.md ...
python3 masechet_2_otzva.py   שלב1.docx הכרעות.json שלב2.docx
```

ואחרי שהגהת:
```
python3 masechet_3_miyun.py   מוגה.docx  דוח-מיון.md
```

## שלושת המנועים

**מנוע א - מכני.** כל הכללים שהצטברו בשמונה סבבים, בהרצה אחת. עברות, קיצורים,
תרגום ארמי ודאי, עוגני חלון 3, סגנון האמוראים, ניקוי תווים ורווחים. כשבע-עשרה
שניות למסכת שלמה, והכל כעקוב-אחר-שינויים.

**מנוע ב - אצווה.** אינו מכריע דבר. מוציא את כל מה שדורש הכרעה - ציטוטים לניקוד
ולסיווג, מילים ארמיות מסופקות - עם ההקשר, ושותל בחזרה את מה שהוכרע.

**מנוע ג - מיון.** קורא את ההגהה שלך וממיין כל תיקון לשלוש שכבות: מכני שנכנס
לטבלאות, סמנטי שהולך לאצווה, ופייבל שאין מה להכליל ממנו.

## הכלל שמחזיק את הכל
כלל נכנס למנוע המכני רק אם התרגום שלו אחד ואינו תלוי בהקשר בשום מקום במסכת,
והמילה מתפקדת כמילה ולא כמונח סוגיה. כל השאר מסופק, ומסופק ממתין.

`ההוא` ו-`בתרא` נדחו על המבחן הזה. `רישא` כמעט עברה אותו ונתפסה בזמן.

## הקבצים
| קובץ | תפקיד |
|---|---|
| `laukmi_rules.py` | **מקור האמת היחיד** לכל הטבלאות |
| `laukmi_mech.py` | מנוע העריכה: החלפה במעקב, סגנון תו, פיצול פסקה |
| `laukmi_aramaic.py` | מילון הארמית הוודאי וגלאי הספק |
| `laukmi_anchors.py` | זיהוי ויצירת עוגני חלון 3 |
| `laukmi_batch.py` | הפקת אצוות ושתילת הכרעות |
| `laukmi_triage.py` | מיון תיקוני המחבר |
| `laukmi_scan.py` | סורק ומדווח בלי לגעת |
| `laukmi_learn.py` | קבלת כל השינויים, וחילוץ תיקוני המחבר |
| `manual.md` | היומן המלא: כל כלל, מאיזה תיקון נלמד, ומה נדחה ולמה |

`run_round5..8.py` ו-`run_full.py` הם הסבבים ההיסטוריים של חולין. אין בהם צורך
למסכת חדשה - מנוע א מכיל את כולם.
