# מנוע ההדפסה ל-PDF (לאוקמי גירסא)

הפקת קובץ PDF בלבד (לא חלון הדפסה של הדפדפן), בעימוד מקצועי בשני טורים על A4, כולל תוספות בהערות שוליים.

## איך זה עובד

1. **המנוע** - `tools/print_engine.js`, מוזרק ל-`mas.js` (הקוד המשותף) של כל מסכת. כשהדף נפתח עם `?print=1`
   הוא מחליף את התצוגה בעמודים: מודד את כל השורות בסרגל אחד ברוחב מסילה+מידה (80 מ"מ), ממלא טור אחר טור
   עד גובה הנטו פחות הערות השוליים של אותו טור, ומציג כל טור כחלון חיתוך על הסרגל. שבירת השורות זהה לאתר.
2. **הפרופיל** - `tools/print/profiles/a4.json`. כל המידות והגדלים שם. פרופיל B5 = קובץ נוסף באותו מבנה,
   בלי מנוע חדש (שדות: page, margins, rail, measure, gap, body, header, footer, notes).
3. **ההפקה** - דפדפן אחד קבוע:
   - שרת: `worker/leokmei-print` (Cloudflare Browser Rendering). `GET /pdf?m=<מסכת>&from=&to=&all=1&tos=0|1&duplex=0|1`.
     מטמון ב-KV (מפתח: בקשה + ETag של דף המסכת + חותמת נוסחי התוספות). רישום ב-D1 (טבלת zs_c, שדה print).
   - מקומי/בדיקות: `tools/print/render_pdf.py` (Playwright). `--dev` מזריק את המנוע והנתונים מן העץ.
4. **הממשק** - כפתור "הדפסה" בסרגל (בטלפון: "עוד" ואז "הדפסה ל-PDF"). חלון: מסכת / פרק / דף / עמוד / טווח,
   "עם תוספות" (פעיל רק בדפים שיש בהם), "דו-צדדי", מספר העמודים הצפוי (חישוב אמיתי), פס התקדמות.

## כללי העימוד שנאכפים (בקוד)

- פרק חדש מתחיל בטור חדש; כותרת אינה נפרדת מן התוכן שאחריה (שתי שורות לפחות).
- אין שורה יתומה או אלמנה (שתי שורות מכל צד); מילה בודדת בשורה אחרונה נמשכת בדחיסה עדינה.
- סימן התוספות והערתו תמיד באותו טור; מתחת לכל טור ההערות בשני טורים קטנים (ארבעה טורי הערות בעמוד),
  וילנא לייט, והד"ה בלבד במשקל אחד יותר (וילנא רגיל). הערה בודדת - ברוחב מלא.
- מדפיסים רק שחור; בלי "מקור", בלי פירוש הגמרא, בלי צורת הדף.
- (11.10 ערב) סימן ההפנייה לתוספות ברוחב אפס ומורם אל הרווח שבין השורות: אינו משנה שבירת שורה. ספרות ולא אותיות, בסימן ובהערה.
- מילה בודדת בשורה אחרונה: דחיסה עדינה; ואם אינה מספיקה - רווח קשיח לפני המילה האחרונה (עד שלוש מילים) כדי שתרד עוד מילה. מה שנותר נרשם ב-issues.
- שמות המפרשים בהערות (רש"י, ר"ת, ר"י...) קטנים ואפורים; בלי נקודה-פסיק (מוחלף בנקודה).
- המרווח הפנוי כולו בין שני הטורים (שוליים: ימין 20, שמאל 10 מ"מ). QR רק בעמוד 2 של מסכת שלמה.
- בקובץ: לחיצה על ציון דף מובילה אל מקומו באתר; לחיצה על סימן הפנייה מובילה להערה (ובחזרה). הצגת ההערה בריחוף אינה נתמכת בקובץ PDF שמפיק הדפדפן.

## בדיקות

- `uv run --with pymupdf python tools/print/check_pdf.py <קובץ.pdf>` - גודל, גופנים מוטמעים, עמודים ריקים, תווים אסורים.
- `uv run --with playwright python tools/print/test_dialog.py --site site --slug kiddushin` - חלון ההדפסה.
- לוח תקלות: `site/print-board.html` (למנהל). קריאת ההצעות: `uv run python tools/print/issues.py`.

## מלכודות שנמדדו

- שני עותקים של המנוע בדף (בנוי + מוזרק) רצים במקביל ומשבשים - `render_pdf.py --dev` מחליף ולא מוסיף.
- הדפסה מיד אחרי העימוד, לפני הצביעה, מניבה קובץ ריק: ממתינים לשתי רשימות-צביעה ו-300 מילישניות.
- מסמך של מאות עמודים נפרס בגוש אחד בדקות: העימוד נעשה בנתחים של כ-150 יחידות.
- `#flow` של האתר מוחלף בזמן הטעינה: המנוע יוצר אלמנט משלו ובודק אחרי כל המתנה.
- בוינדוס נקודותיים אסורות בשם קובץ: מוחלפות ב-U+A789.
- וילנא לייט (`BA•Vilna-Light.otf`) נטען רק בהדפסה: `fonts/vilna-l.*`.
- ה-Worker חוסם בקשות בלי User-Agent של דפדפן (קוד 1010 של Cloudflare).
