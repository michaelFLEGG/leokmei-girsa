## א. קושיה ותירוץ בשורה אחת - "והך" / כותרת שממשיכה (כללים 21, 37)

1. (ח.) לפני:
```
[צד:ויקשה:]
והרי שנינו: 'אל ידור'!
[צד:-]
כאן - בכפוף לו, וכאן - בשאינו כפוף לו.
```
אחרי:
```
[צד:והך:]
{אם:דשנינו:} 'אל ידור'! - {אם:כאן -} בכפוף לו, {אם:וכאן -} בשאינו כפוף לו.
```

2. (ב:) לפני:
```
[צד:ויקשה:]
דברי ר"מ סותרים זה את זה!
[צד:-]
שני תנאים הם לשיטת ר"מ.
```
אחרי:
```
[צד:ודברי ר"מ:]
לא סותרים זה את זה! - דשני תנאים הם לשיטת ר"מ.
```
וכן מיד אחריו: `[צד:ודברי ר"א:]` `לא סותרים זה את זה! - א. דשני תנאים הם לשיטת ר"א,` (שלוש שורות לאחת).

3. (יג.) לפני:
```
[צד:ויקשה:]
והרי כתוב 'אשר בחרת באברם'!
[צד:-]
שם הנביא מסדר בשבחו של מקום מה שהיה בתחילה.
```
אחרי:
```
[צד:והך:]
ד'אשר בחרת באברם' - שם הנביא מסדר בשבחו של מקום מה שהיה בתחילה.
```

4. (ד.) לפני:
```
'לולא האמנתי לראות בטוב ה' בארץ חיים', ונקוד על 'לולא', שאמר מובטח אני... אבל איני יודע אם יש לי חלק ביניהם!
[צד:-]
שמא יגרום החטא,
```
אחרי: שורה אחת - `...אבל איני יודע אם יש לי חלק ביניהם! - שמא יגרום החטא,` (המקף נכנס לתוך השורה, כותרת הצד בוטלה).

5. (ג.) כותרת צד שהשורה ממשיכה ממנה: לפני `ומה מונה ר"א - תחילת המשמרות או סופן?` | `והרי תחילת הראשונה - ערב, וסוף האחרונה - יום!` אחרי: `[צד:ומה ר"א]` `מונה תחילת או סוף המשמרות {הס:הרי תחילת הראשונה ערב, וסוף האחרונה יום}` - שאלה וקושייתה בשורה אחת, הקושיה בסגנון הסבר.

7. (י.) `[צד:רב ושמואל:]` `{אם:א.} עלייה פרועה היתה וקירוה, {אם:ב.} אכסדרה גדולה היתה וחלקוה` - שתי הדעות בשורה אחת, במקום כותרת צד לכל אחת.

## ג. דו-שיח קצר - פסקה אחת (הגדרה 34)

8. (ג.) לפני: שש שורות, כל אחת בכותרת צד (`[צד:א"ל:]` / `[צד:ואמרתי:]` / `[צד:וא"ל:]`). אחרי: פסקה אחת -
`פעם אחת הייתי מהלך בדרך, ונכנסתי לחורבה להתפלל, ובא אליהו ושמר לי על הפתח עד שסיימתי תפלתי. {אם:א"ל} שלום עליך, רבי! {אם:אמרתי} שלום עליך, רבי ומורי! {אם:וא"ל} בני, מפני מה נכנסת לחורבה זו? {אם:אמרתי:} להתפלל...`
וכן: `מה קול שמעת בחורבה זו? {אם:אמרתי:} בת קול שמנהמת כיונה ואומרת: 'אוי שהחרבתי את ביתי...'. {אם:א"ל:} חייך, לא בשעה זו בלבד...`

9. (ט:) לפני: `דיה לצרה בשעתה.` | `[צד:א"ל הקב"ה:]` `לך אמור להם: 'אהיה שלחני אליכם'.` אחרי: `דיה לצרה בשעתה. {אם:א"ל הקב"ה:} לך אמור להם: 'אהיה שלחני אליכם'.`

## ד. גוש - שורות המשך וזנבות מתאחדים (כלל 23, הגדרות 31-33, 48)

10. (ג:) שלוש שורות לאחת: `לכו ופשטו ידיכם בגדוד.` | `ומיד יועצים באחיתופל ונמלכין בסנהדרין,` | `ושואלין באורים ותומים.` -> `לכו ופשטו ידיכם בגדוד. ומיד יועצים באחיתופל ונמלכין בסנהדרין, ושואלין באורים ותומים.`

11. (ו:) רשימה ממוספרת בשורה אחת: `אדם שיש בו ירא"ש - א. דבריו נשמעין,` | `ב. העולם כולו נברא בשבילו, ג. שקול כנגד כל העולם,` | `ד. כל העולם נברא לצוות לו.` -> שורה אחת. וכן (ח:) `א. השלימו שמו"ת, ב. הזהרו בורידין כר"י, ג. והזהרו בזקן ששכח תלמודו...`.

12. (י:) זנב הסבר: `{כת:יתפלל במקום נמוך}, ד{פס:'ממעמקים קראתיך ה''},` | `שאין גבהות לפני המקום.` -> `{כת:יתפלל במקום נמוך}, ד{פס:'ממעמקים קראתיך ה''}, {הס:שאין גבהות לפני המקום}.`

13. (י.) פסוק הראיה מצטרף: `אף חרב חדה מונחת על צוארו של אדם - אל ימנע עצמו מן הרחמים,` | `ד'הן יקטלני לו איחל'.` -> שורה אחת.

14. (י.) "כנגד הקב"ה וכנגד נשמה:" + שלוש שורות המשך -> פסקה אחת (3:0.22 + 2:0.20 -> 4:0.37 - שורה שלמה נחסכה, זנב אחד במקום שניים).

15. (ח:) הלכה בסוף השורה: `ויוצא בהן יד"ח של יום ושל לילה,` | `ואף שלילה הוא, קורא לו יום מפני הקמים באותה שעה.` | `והלכה כרשב"י.` -> `ויוצא בהן יד"ח של יום ושל לילה, ואף שלילה הוא, קורא לו יום מפני הקמים באותה שעה. - {ב:והלכה כרשב"י.}`

## ה. מעוין לרצף מימרות קצרות (כלל 24, הגדרה 30)

16. (ז:) לפני:
```
(רווח) מיום שברא הקב"ה את העולם לא קראו אדם אדון, עד שבא אברהם, ואף דניאל נענה בשביל אברהם שקראו אדון.
(רווח) לא היה אדם שהודה להקב"ה עד שבאה לאה והודתו.
(רווח) ראובן - ראו מה בין בני לבן חמי...
```
אחרי: הראשונה נשארת, וכל מימרה אחריה `(מעוין) ...` בלי (רווח). וכן ו: "יזהר בתפלת המנחה", "הנהנה מסעודת חתן", "אדם שיש בו ירא"ש", "יקדים שלום"; ח. "יש זקנים גם בבבל", "לעולם יכנס אדם בביהכנ"ס", "גדול הנהנה מיגיעו".

## ו. כותרת נושא - הפתיחה נבלעת בה (כללים 25, 39)

17. (ט.) לפני: `(נושא) אכילת פסח - עד חצות או עד עלות השחר` | `{הס:ובאכילת פסחים חלקו:}` אחרי: `(נושא) אכילת פסח - נחלקו עד חצות או עד עלות השחר` ושורת הפתיחה נמחקה.

18. (ד:) לפני: `(נושא) מעופם של מיכאל וגבריאל` | `גדול מה שנאמר במיכאל יותר מבגבריאל:` | `במיכאל 'ויעף אלי...',` | `ובגבריאל 'בתחלה מועף ביעף'.` אחרי: `(נושא) גדול מה שנאמר במיכאל יותר מבגבריאל` | `במיכאל 'ויעף אלי אחד מן השרפים', ובגבריאל 'בתחלה מועף ביעף'.` (ארבע שורות לשתיים).

19. (ח:) ד"ה עם הלכה: `{ד"ה:ר"ג עד שיעלה עמוד השחר}` | `{כת:והלכה} {אם:כר"ג}.` -> `{ד"ה:ר"ג עד שיעלה עמוד השחר - וכן הלכה}`.

## ז. כותרת צד קצרה ומילת ניגוד (הגדרות 35, 43, 44)

20. (יב:) `ולא מ'בכפרי לך...' - שמא צבור שונה,` | `אלא משאול, שהתבייש...` -> `[צד:ולא]` `מ'בכפרי לך...' - שמא צבור שונה,` | `[צד:אלא]` `משאול, שהתבייש...` - נראה כטבלה.
21. (ו.) `ובשאר בתים: א. 'כי מי' 'ומי', ב. ... ובשל יד - כולם בבית אחד.` -> `[צד:ובשאר בתים:]` `א. 'כי מי' 'ומי', ב. 'אשריך ישראל', ג. 'או הנסה', ד. 'ולתתך עליון',` | `[צד:ובשל יד]` `- כולם בבית אחד.`
22. (ה.) `ר"ז: מדת הקב"ה שלא כמדת בשר ודם:` -> `[צד:ר"ז:]` `מדת הקב"ה שלא כמדת בשר ודם:`; (יב.) `וכן תנן משמר היוצא אומר...` -> `[צד:וכן תנן]` `משמר היוצא אומר...`.

## מה המשותף
יחידת רעיון אחת בשורה אחת, ופסקה שנראית שלמה וסימטרית. מיכאל **מקטין** את מספר השורות (איחוד, כותרת שבולעת, מעוין במקום רווח), ומקצר נוסח רק כדי שהרעיון ייכנס לשורה. בסבב הזה כל הצעה צריכה להיראות כמו אחת מקבוצות א-ז.
