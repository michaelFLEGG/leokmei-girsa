# תוספות בהערות שוליים (לאוקמי גירסא)

**עדכון 12.10.2026:** נוסף מבחן מנועים עיוור בסוכה (מב. עד מד:), ראו הסעיף "מבחן המנועים העיוור" בסוף הקובץ.

שכבה שבה כל דיבור המתחיל של תוספות הוא הערת שוליים נפרדת, בתמצית "מה יוצא מהתוס'", וממוספרת ברצף לפי הפרק.
הוחלט והופעל ב-11.10.2026. ניסוי ראשון: קידושין פרק א, דף יד: (תוספות קל"ד עד קל"ז). הורחב ב-11.10.2026 עד טז: (קל"ח עד קנ"ט).

## מבנה

| קובץ | תפקיד |
|---|---|
| `raw/<מסכת>.json` | הטקסט הגולמי מספריא (תוספות, מהדורת וילנא). אינו נערך. |

| `<מסכת>/count-<פרק>.json` | **הספירה הקבועה**: מספר סידורי לכל תוספות. נבנה בכלי, אינו מחושב מחדש בטעינה. |
| `<מסכת>/verification-<פרק>.md` | מה נמדד מול המקור השני, ומה הוסר ולמה. |
| `<מסכת>/styles-<פרק>.json` | הנוסחאות לכל תוספות (נכתבו במודל החזק, נבדקו בידי מבקר נפרד). קל"ד עד קל"ז: חמש נוסחאות. קל"ח ואילך: שתיים בלבד, א (שורה אחת, ברירת מחדל לפי בחירת המנהל) ו-ב (מהודק ומובן, להשוואה). |
| `<מסכת>/anchors-<פרק>.json` | עוגן הסימן בדף: קטע טקסט ומספר מופע, לא מיקום תו. השדה `page` (אופציונלי) מציין עמוד אחר באתר כשהטקסט שהתוספות מתייחס אליו מוצג בעמוד סמוך (למשל תוספות קנ"ו, שורת גמרא טז.:1, יושבת בסוף עמוד טו:). |
| `<מסכת>/live-<פרק>.json` | מה שהבנייה קוראת: רק תוספות שנכתב להם סיכום ויש להם עוגן. |
| `תוס-פרומפט-סיכום.md` | פרומפט הכתיבה, מתעדכן אחרי כל סבב בחירות. |
| `תוס-למידה.md` | בחירות המנהל, עריכות והערות (נוצר מנקודת הקליטה). |

## כלים (`tools/tosafot/`)

הרצה תמיד דרך `uv run`:

1. `fetch_tosafot.py <מסכת> 2a 41a` - מושך מספריא.
2. `build_count.py <מסכת> <פרק>` - בונה את הספירה הקבועה ואת דוח האימות.
3. `make_live.py <מסכת> <פרק>` - מרכיב את `live-N.json` לבנייה.
4. `push.py <מסכת> <פרק>` - מעלה את הנוסחאות לנקודת הקליטה, למסך הבחירה של המנהל.
5. `learn.py <מסכת>` - מושך את בחירות המנהל אל `תוס-למידה.md`.

## איך זה עובד באתר

- הבנייה מזריקה `window.__TOS` ואת `tools/tosafot_ui.js` רק למסכת שיש לה `live-*.json`. אין קוד ואין כפתור באף מסכת אחרת.
- הבחירה של המנהל נשמרת בנקודת הקליטה (`/tos`) ומוצגת לכל הלומדים מיד, בלי בנייה מחדש. עד שנבחר - מוצג נוסח ב (מהודק ומובן).
- הסימנים אינם בקובצי הוורד. הם נבנים מעל הדף אחרי כל רינדור, ומוסרים במצב עריכה, הצעה, תצוגת ספר והדפסה.
- עוגן שלא נמצא (הטקסט נערך): הסימן עובר לסוף שורת הגמרא הקרובה, מסומן אדום, ומופיע למנהל "העוגן זז". לעולם לא נעלם.
- בדיקת שלמות: מספר הסימנים שהונחו בעמוד שווה למספר התוספות שבקובץ; אחרת אזהרה גלויה למנהל.

## מתוכנן ולא נבנה (במכוון)

1. ייצוא להערות שוליים אמיתיות בוורד ובספר המודפס (שורה של 6 ס"מ). השכבה בנויה כך שכל הערה נושאת מספר, דיבור וטקסט.
2. "בחן את עצמך" לפי מספר התוספות ("מה תירץ תוס' קל"ז?").
3. מונה "תוספות שנלמדו" במערכת הלומד (הערות תוספות אינן נספרות כדפים שהספיק).
4. הצעות תיקון של מבקרים על ההערות, באותו מנגנון "הצע תיקון".
5. עמודה "תוס'" ב"מפת העבודה" לכל פרק.


## מבחן המנועים העיוור (12.10.2026, סוכה מב. עד מד:, וקידושין יד:)

המטרה: לבחור מנוע אחד לכתיבת "שורה אחת" לכל תוספות בכל הש"ס, כשכל המנועים כותבים באותו נוסח בדיוק, והמנהל בוחר בלי לדעת מי כתב מה.

| קובץ | תפקיד |
|---|---|
| `תוס-פרומפט-שורה-אחת.md` | ההנחיה הקבועה היחידה. החלק הקבוע (כללים ודוגמאות) ראשון, ולכן מתאים למטמון פרומפט ב-Batch API. החלק המשתנה (התוספות והקשרו) נבנה בקוד. |
| `run-config-sukkah-test.json` | ההגדרות: מנועים, טווח עמודים, מצב (`direct` קריאות ישירות; `batch` הכנת קובץ בקשות ל-Batch API בלבד), מחירי Batch שנבדקו, ותקציב טוקנים. שינוי הגדרה בלבד מעביר למנוע אחד, ל-Batch ולמסכת אחרת. |
| `sukkah/chapters.json` | גבולות הפרקים לפי ספריא, כולל גבול באמצע עמוד (פרק ד נפתח בשורה 5 של מב:). |
| `sukkah/count-<פרק>.json` | הספירה הקבועה, פרקים א עד ד (עד מד:). המספור ברצף לפי הפרק. `verification-<פרק>.md`: אין מקור שני (ויקיטקסט חסום מסביבת הענן). |
| `sukkah/anchors-<פרק>.json` | עוגן הסימן בדף. הוצע בידי מודל ואומת בקוד (הקטע קיים בדף, מספר המופע מחושב בקוד). כלל 3 הוא הנסיגה. |
| `sukkah/context.json` | שורות הלאוקמי גירסא כפי שהן באתר, ושורות הגמרא של ספריא, לכל עמוד. |
| `sukkah/engines/` | הפלט הגולמי של כל מנוע לכל עמוד, עם ספירת הטוקנים, והמבקר (`review--*.json`). |
| `sukkah/test-options.json` | מה שהאתר טוען לכרטיסים: חמש אופציות באותיות א-ה בסדר מוגרל לכל תוספות, **בלי שם מנוע**. |
| `sukkah/test-reveal.json` | המיפוי אות-מנוע, הטוקנים, מחירי Batch וסימוני המבקר. נטען לדף רק בלחיצה על "חשוף את התוצאות". |
| `engines-usage.json` | יומן צריכת הטוקנים המצטבר של המבחן (תקציב 3 מיליון). |

כלים (`tools/tosafot/`): `fetch_tosafot.py` → `build_count.py` → `extract_context.py` (אחרי בנייה מקומית) → `make_anchors.py` → `run_engines.py ... run` → `... review` → `... pack` → `make_live.py`. בדיקת דפדפן: `qa_blind_ui.py` (עם `mock_tos_server.py`).

מפתח התוספות בדף ובנקודת הקליטה: בקידושין `n` כמות שהוא; בשאר המסכתות `פרק*1000+n` (למשל 3122 ו-4001), והמספר המוצג ללומד (`disp`) הוא המספר בפרק.

עריכות והערות המנהל נקראות מנקודת הקליטה ב-`learn.py <מסכת>`, שמפענח את האותיות לפי `test-reveal.json` ורושם ב-`תוס-למידה-<מסכת>.md`.
