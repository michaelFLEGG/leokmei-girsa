# המרת ממצאי בקרה למטען מוכן - הנחיות למודל (פרומפט 8, 26.10.2026)

אתה מקבל קובץ JSON של ממצאי בקרה מספר "לאוקמי גירסא" (קיצור התלמוד הבבלי בעברית-ארמית, בסגנון ראשי תיבות).
לכל ממצא כתוב **פעולה מוכנה להחלה** (op), שהמחבר יאשר בלחיצה אחת. לא הסבר, לא שאלה - נוסח מוכן.

לכל פריט יש: id, det (סוג), kind, mark (הקטע המסומן), fix (מה הבודק ביקש), note (מה נמצא),
head (כותרת הצד של היחידה - "חלון 3"), line (השורה שבה הממצא), prev / next (השורות הסמוכות).

## הפלט

מערך JSON בלבד, פריט לכל ממצא, באותו סדר:

```
{"id": "...", "op": {...}, "alts": [{...}, {...}]}
```
או, כשאין מה לשנות (הממצא שגוי, הטקסט כבר תקין, או שאי אפשר להכריע בלי הגמרא):
```
{"id": "...", "skip": "סיבה קצרה בעברית"}
```
alts: עד שני נוסחים חלופיים, רק כשהם שונים באמת. לא חובה.

## מבני op

- `{"rep": {"x": "קטע מדויק מן השורה", "y": "הנוסח החדש"}}` - החלפה. x חייב להופיע בשורה אות באות, פעם אחת בלבד (אם קצר מדי - הרחב אותו במילה או שתיים).
- `{"ins": {"after": "עוגן מדויק מן השורה", "text": "הטקסט שנוסף"}}` (או "before", או `"end": true`) - הוספת הסבר; הטקסט נכנס בסוגריים מרובעים בסגנון "הסבר", ואין לכתוב את הסוגריים בעצמך.
- `{"anchor": {"text": "כותרת הצד החדשה", "rest": "מה שעובר לראש השורה"}}` - קיצור כותרת צד.
- `{"heading": {"text": "כותרת נושא של 2-6 מילים"}}` - כותרת לפני הפסקה.

## לפי סוג

### anchor - "עוגן חלון 3" (כותרת צד ארוכה מ-20 תווים)
כותרת הצד היא הדובר או הייחוס שפותח את המימרא, עם נקודתיים בסוף. קצר אותה עד 20 תווים לכל היותר:
- `text` = הדובר (השם, "אמר X", "א"ר X", "דתניא", "ואב"א", מספר א./ב. שלפניו) עם הנקודתיים.
- `rest` = שאר המילים שהיו בכותרת, והן עוברות לראש השורה, באותו סדר ובאותו כתיב.
- **אסור** להוסיף מילה, למחוק מילה או לשנות כתיב: כל מילות הכותרת הישנה = מילות text + מילות rest, בדיוק.
- כלל 17 של המחבר: דובר יוצא לכותרת צד כשהמימרא שאחריו ארוכה משורה; צלעות מקבילות (מחלוקת, א. ב.) באותה צורה.
- כשהכותרת היא שאלה או תוכן ולא דובר (למשל "דבר המסויים- אמר רב יוסף:"): text = הדובר ("אמר רב יוסף:"), rest = התוכן ("דבר המסויים-").
- תן alt כשיש חיתוך סביר אחר (למשל עם "אלא" בכותרת או בשורה).

### abbr - "סימני קיצור" (גרש יחיד)
הכרע לפי השורה: ראשי תיבות (גרש בין אותיות, כמו י'ח, ר'מ) → גרשיים לפני האות האחרונה: `י"ח`, `ר"מ`.
קיצור של מילה (וכתי', אפי', מתני', וגו') → תקין: skip.
פתיחת ציטוט שחסר לה גרש סוגר → rep שמוסיף את הגרש הסוגר בסוף הציטוט (x = מילת הסיום, y = אותה מילה עם ').
מותר לשנות רק גרש וגרשיים - לא אות.

### punct - "פיסוק וסוגריים" (סוגר מרובע שאינו מאוזן)
קרא את השורה: אם הסוגר הנגדי חסר - הוסף אותו במקום הנכון (בדרך כלל אחרי ההסבר שנפתח); אם הסוגר מיותר - הסר אותו.
אם בשורה הסוגריים כבר מאוזנים - skip ("מאוזן").
מותר להוסיף או להסיר סוגר בלבד: x ו-y זהים חוץ מהסוגר.

### orphan - "אות תלושה בסוף שורה"
אם האות היא שארית - rep שמסיר אותה; אם היא תחילת מילה שנקטעה - skip.

### תוכן (sk_step, sk_miss, sk_pshat, sem_lo, sem_hav, sem_yih, sk_head, nose_long, hash, sem_sty, sk_q ...)
כתוב את ההשלמה עצמה לפי fix ו-note, קצרה ככל האפשר, בלשון הלאוקמי (ראשי תיבות מקובלים, משפטים קצרים):
- "חסר שלב" / "תוכן שלא הובא" / "לא מובן" → ins במקום המדויק (after / before / end). הטקסט עצמו בלי סוגריים.
  דוגמה מכוילת של המחבר: `למה בכור ינכה? יאמר לו מאי הפסדתיך?`
- "טעות בפשט" → rep של הקטע השגוי בנוסח הנכון (אם fix כבר נותן נוסח - השתמש בו).
- "כותרת (סקירה)" → heading. "כותרת ארוכה מדי" → rep של הכותרת בנוסח מקוצר (רק החידוש).
- "סימן #" → rep שמסיר את ה-# ומקצר את הקטע שלפניו, בלשון מסורתית.
- כשהבקשה היא בדיקה שאי אפשר לעשות בלי הגמרא ("לאשר ש...", "לבדוק") → skip.
- לעולם לא פרט הלכתי שאינו בסוגיה, ולעולם לא העתקה של חמש מילים רצופות מביאור חברותא.

## חשוב
- הפלט הוא JSON תקין בלבד, בלי הסברים לפניו או אחריו.
- כל x / after / before מועתק מן השורה (line) אות באות, כולל גרשיים, ניקוד ופיסוק.
- מקף ארוך אסור: רק "-".
