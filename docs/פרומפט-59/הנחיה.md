# סבב מבני לפי עריכות מיכאל בברכות פרק א (פרומפט 59, 17.11.2026) - הנחיה לעובד

`runner.mjs next` מציג את הקובץ הזה, ואת `docs/פרומפט-59/דוגמאות.md`, לכל עבודה ששמה כולל "סבב מבני". הוא גובר על כלל כללי.

**למה:** ההצעות של פרומפט 58 בסוכה היו "מאוד דלות" (מיכאל): רובן החלפות מילה ("אף" במקום "אפי'"), ולא העריכה שהוא עשה בברכות פרק א. נשארו כותרות צד כמו "ואביי הקשה" / "ושוב הקשה אביי" שהיו צריכות להפוך ל"והך" ולהתאחד עם התירוץ. **זה סבב צורה ומבנה** על נוסח שמיכאל כבר הגיה. נוסח תוכני משתנה רק כשכלל מחייב זאת. הכרעות קודמות נשארות.

## רשימת הבדיקה המבנית - לכל קטע, במפורש
1. **קושיה ותירוץ** שנכנסים בשורה אחת? -> `[צד:והך:]` / `[צד:וקשה:]` / כותרת שהשורה ממשיכה ממנה, הקושיה, מקף, התירוץ - באותה שורה (כללים 21, 37). כותרת צד כמו "ויקשה", "ואביי הקשה", "ושוב הקשה", "ותירץ", "והקשו" - תמיד הצעה.
2. **מחלוקת** ששתי צלעותיה נכנסות בשורה? -> שני השמות בכותרת הצד, או `{אם:א.}... {אם:ב.}...` (כלל 22, הגדרה 36). "חד אמר... וחד אמר" / "ולא נתפרש" -> שני השמות בכותרת.
3. **שורות שגולשות במילה או שתיים, זנבות, שורות המשך** (מצב ותוצאה, מימרה ונימוקה, שני חצאי רשימה, פסוק ראיה בשורה משלו) -> גוש אחד, זנב בסגנון `{הס:}`, ופסוק הראיה "ד'...'" בסוף השורה (כלל 23, הגדרות 31-33, 48).
4. **רצף מימרות קצרות** עם (רווח) חוזר -> `(מעוין)` מן השנייה ואילך, בלי רווח (כלל 24, הגדרה 30).
5. **כותרת שהשורה אחריה חוזרת עליה, ושורת פתיחה שתוכנה כבר בכותרת** -> נבלעת בכותרת (כללים 25, 39). שאלה שפותחת עניין -> (נושא) (הגדרה 47).
6. **כותרת צד ארוכה משתי מילים** או כותרת צד שהיא בעצם תיאור ("ואביי הקשה") -> עד שתי מילים, מילת מהלך או דובר (+ נמען בר"ת, הגדרה 35).
7. **דו-שיח קצר** בסיפור, שורה לכל אמירה קצרה -> פסקה אחת, הדוברים ב-`{אם:}` (הגדרה 34).
8. **הלכה בשורה משלה** -> לסוף השורה או לד"ה (הגדרה 38). מקור "שנינו" -> תנן / תניא בכותרת צד (הגדרה 42, כללים 26-29).

## מה לא להציע
- **החלפת מילה לבדה** (אף/אפי', כתיב, ראשי תיבות) שאינה משנה מבנה ואינה חוסכת שורה - **אל תציע**. מותר רק בתוך הצעה מבנית, או כשהיא חוסכת שורה (ואז כתוב זאת ב-changes).
- קטע שאין בו מקום מבני אמיתי - `nochange`. עדיף nochange מהצעת מילים.
- אל תשנה תוכן, אל תקצר שקלא וטריא, אל תוסיף השלמות (שכבות 2 ו-3 כמעט אינן בסבב הזה: רק אם חסרה מסקנה ממש).

## חובות בכל פריט
