# הפעלת הסקירה - לווקר ("הרץ סקירות ממתינות")

מסלול רגיל, במכסת המקס, בלי משימה מתוזמנת בענן (המשימות המתוזמנות מושהות; ראה בסוף).

## 0. תנאי פתיחה
- `git pull`; נעילה `.locks/skira.lock` (נוהל `CLAUDE.md`); קובץ הוורד המקורי לא נערך בשעה האחרונה.
- מפתח המנהל: `C:\Users\Owner\Documents\לאוקמי-מפתח-מנהל.txt` (נקרא בידי `_api.py`; אין להדפיס).

## 1. למידה (זול, בלי מודל חזק)
```
uv run --with lxml python tools/skira/learn.py
```
מושך הכרעות ושרשורים, מעדכן `review-rules.md`, `suppress.json`, דף הכיול ו"מה למדתי".
אם נוצר `data/skira/distill-input.json` עם פריטים: סוכן **sonnet** לפי `prompts/distill.md`, ואז `learn.py --no-pull` שוב.

## 2. תשובות לשרשורי "שוחח"
```
uv run python tools/skira/queue.py replies
```
לכל שרשור שהמחבר כתב בו אחרון: קרא את ההערה והמקור, ענה (עברית, קצר, הודה אם טעית) ב-`POST /skira/thread` עם `who:"c"`.
תשובה שמשנה הכרעה: אל תשנה בעצמך; המחבר מכריע.

## 3. הבקשות בתור
```
uv run python tools/skira/queue.py list
uv run python tools/skira/queue.py claim <מזהה>
```
לכל בקשה (מסכת, מדף, עד דף, עומק):
1. `uv run --with lxml python tools/bakara/run.py <מסכת> <פרק> --no-push --no-sync --gemara-only` לכל פרק שהטווח נוגע בו (שכבה 0; לא דורס קובץ עם ממצאי מודל).
2. `uv run --with lxml python tools/skira/engine.py prep <מסכת> <מדף> <עד דף> --depth <fast|full>`: מדפיס אומדן וחריגה מהתקרה. **חריגה: עצור ודווח.**
3. שכבה 1: סוכן לכל קבוצה ב-`tasks.md`, לפי `prompts/triage.md`. מודל לפי ההכרעה ב"דוח הסקירה" (ברירת מחדל: sonnet). כותבים ל-`triage-out/T_<מודל>.json`.
4. `engine.py prep2 ...`: בוחר את הפסקאות המסומנות + מדגם 10%, ומכין את `l2-in.txt` ו-`l2-src.md`.
5. שכבה 2 (עומק "מלאה"; ב"מהירה" נשארים בשכבה 1 ובקוד): סוכן **opus** אחד לכל כ-60 פסקאות, לפי `prompts/reviewer.md` + `review-rules.md`. כותב ל-`review-out/R_<n>.json`.
6. `engine.py merge ...`: מאחד, מעדכן טביעות ומעלה לנקודת הקליטה.
7. `queue.py done <מזהה> "<כמה הערות, כמה טוקנים>"`.
8. דוח טוקנים: `data/bakara/costs.json` (שורה לכל שכבה).

## 4. סיום
