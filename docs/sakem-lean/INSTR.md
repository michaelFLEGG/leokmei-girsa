# משימה: דיאטת כללים לסכם (פרומפט 70) - זיקוק בלי אובדן

אתה מקבל קובץ chunkN.md: לקחים שנלמדו מעריכות המנהל (מיכאל) בכלי "סכם" שמהדק ומעצב את "לאוקמי גירסא" (סיכום גמרא). כל יחידה מתחילה במזהה [L123] או [R45].
הכותב (מודל) קורא את כל הלקחים בכל הרצה, וזה יקר. המטרה: לזקק אותם לכללים קומפקטיים **בלי לאבד שום לקח**.

כללי הזיקוק:
1. כל לקח נשאר - רק נוסח קצר יותר. כלל אחד יכול לאחד כמה יחידות שאומרות אותו דבר (כפילויות). כלל שהתחדד מחליף את קודמו. כשיש סתירה - הלקח המאוחר (מספר שורה גבוה יותר, או תאריך מאוחר) גובר, והמוקדם מסומן "בוטל".
2. שמור את הסימונים הטכניים בדיוק: {אם:..} {ב:..} {הס:..} {כת:..} [צד:..:] (רווח) (מעוין) (נושא) [משנה:..] וכדומה, וגם מילים ספציפיות שמיכאל מחליף ("לאו" -> "לא").
3. דוגמה קצרה אחת (לפני -> אחרי, עד כ-15 מילים) רק כשהיא נחוצה כדי להבין את הכלל. בלי רשימות של מקומות, תאריכים, מספרי עריכות, שמות קבצים או סיפורי רקע ("נלמד ב...").
4. לכל כלל: נושא אחד מתוך: "ליבה" (חל על כל פרק) / "משנה" (תיבת משנה, הדגשה, ד"ה משנה) / "אגדתא" (סיפורים, דרשות, מימרות אגדה) / "כותרות" (כותרות צד, נושא) / "עימוד" (אורך שורות, איחוי, שורות גולשות, מעוין, רווח) / "מחלוקות" (דעות, מספור, מקף תירוץ) / "השלמות" (הבאת גמרא שחסרה, קיצור מרחבי) / "מסכת:<slug>" (רק למסכת מסוימת - ערכין arakhin, שבת shabbat וכו', כשהלקח באמת ספציפי לתוכן המסכת) / "תהליך" (נוהל עבודה של הכלי: put, finish, סבבים, keep, changes - לא כלל ניסוח).
   בספק - "ליבה". "ליבה" צריכה להישאר קטנה, אבל לקח שחל כמעט על כל פרק - ליבה.
5. "החלפת מילה" (R עם "בעל הפרויקט מחליף X ב-Y"): אחד את כולן לכלל אחד או כמה בפורמט קצר "X->Y, X->Y, ..." (שמור את ההסתייגות: רק בניסוח חדש, לא לשנות נוסח מקור שלא נגעת בו), סמן code:true ושדה pairs: [["X","Y"],...].
6. כלל שכבר כתוב שהוא "נבדק בקוד" / "נאכף בקוד" / "עוצר את put" - סמן code:true, והשאר את הטקסט קצר מאוד (שם הכלל ומה בודקים).

הפלט: קובץ JSON (מערך) בנתיב שנמסר לך, בלבד:
[{"text":"<הכלל בקצרה>","src":["L170","R12",...],"topic":"ליבה","code":false}, ...,
 {"cancelled":["L201"],"by":"L455","why":"<משפט קצר>"}]
**כל מזהה שבקובץ חייב להופיע בדיוק פעם אחת**: ב-src של כלל אחד, או ב-cancelled. בסוף בדוק בעצמך (בסקריפט node או python) שכל המזהים בקובץ הקלט מופיעים בפלט ושאין מזהה מומצא. יעד אורך: סך כל ה-text כרבע עד חמישית מאורך הקלט, בלי לוותר על לקח.
כתוב בעברית, בלי מקף ארוך ובלי נקודה-פסיק. החזר בסוף רק: מספר הכללים, סך התווים, ושהבדיקה עברה.
