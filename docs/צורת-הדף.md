# צורת הדף (8.10.2026)

מקור: קובץ PDF פרטי בתיקיית `Desktop\שיננא לHTML\צורת הדף\<מסכת>\`. מסכת חדשה = תת-תיקייה חדשה, ואז:

    uv run --with pymupdf --with pillow python tools/tzura/build.py <slug>
    python tools/tzura/check.py

- `tools/tzura/build.py` מיישר את קטעי ספריא (`data/sources`) אל שורות הגמרא שבעמוד (ברמת אות), מאמת סימן דף מול הרצף, וכותב `data/tzura/<slug>/*.json` (קואורדינטות בלבד) ו-`data/tzura/manifest.json`. התמונות הפרטיות נכתבות ל-`_work/tzura/assets/` (לא במאגר).
- מסכת שבמניפסט: הכפתור "צ" מופיע ליד "מקור" (Alt+צ). מסכת שאינה בו: אין קוד ואין כפתור.
- הצמדה לפי `data-ref` של השורה (לא לפי התאמת טקסט). קטע בלי מיקום בטוח: עמעום עדין של שולי הדף + "מיקום משוער".
- שכבת הטקסט של ה-PDF אינה מוגשת. ה-PDF המלא אינו עולה לשום מקום.
- הגשה בייצור: R2 + נתיבי `/tz/*` ב-Worker (כתובים ב-`worker/leokmei-suggest/src/index.js`, לא נפרסו). נדרשים: דלי R2 בשם `leokmei-tzura` (חינמי), קשירת `TZURA`, הסוד `TZ_SECRET`, העלאת `_work/tzura/assets/<slug>/` לדלי.
- בדיקה מקומית: `uv run python tools/serve.py --port 8741` (מגיש גם `/tzimg/`).
- נותר: כיול ידני של המנהל (שלב ג), קישור עמוק יפה `leokmei.com/ברכות/ב./צורת-הדף`, הטמעה במסך מפוצל/חיפוש/מערכת הלומד.
