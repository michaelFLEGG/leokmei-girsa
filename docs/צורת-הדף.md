# צורת הדף (8.10.2026, הורחב 12.10.2026 לסוכה ולביצה)

מקור: קובץ PDF פרטי בתיקיית `Desktop\שיננא לHTML\צורת הדף\<מסכת בעברית>\צורת הדף NN-<מסכת>.pdf`. מסכת חדשה = תת-תיקייה חדשה, ואז:

    uv run --with pymupdf --with pillow python tools/tzura/build.py <slug>
    uv run --with pymupdf python tools/tzura/verify.py <slug>
    python tools/tzura/check.py
    bash tools/tzura/upload_r2.sh <slug>

- `tools/tzura/build.py` מיישר את קטעי ספריא (`data/sources`) אל שורות הגמרא שבעמוד (ברמת אות), מאמת סימן דף מול הרצף, וכותב `data/tzura/<slug>/*.json` (קואורדינטות בלבד) ו-`data/tzura/manifest.json` (build_all מעתיק ל-site/tzura). התמונות הפרטיות נכתבות ל-`_work/tzura/assets/` (לא במאגר).
- **קובץ מקור בצורה שונה (סוכה וביצה, מהדורת עוז והדר):** תיבת החיתוך של העמוד גדולה מתיבת העמוד (842x1191 סביב 538x808). הבנייה מיישרת אותה בזיכרון (`set_cropbox(mediabox)`), והסימן ("ב.", "ב:") מזוהה גם כשהוא טוקן אחד. אין קוד לפי מסכת.
- `tools/tzura/verify.py`: מדידה בלתי-תלויה. לכל קטע ודאי משווה את שלד האותיות של הקטע לטקסט שבמלבנים שנשמרו. חשוד = כיסוי מתחת ל-0.7 (בפועל: קטע שמתחיל בצד הקודם, או הבדל נוסח), וכן חריגות סדר.
- מסכת שבמניפסט: הכפתור "צ" מופיע ליד "מקור" (Alt+צ). מסכת שאינה בו: אין קוד ואין כפתור.
- הצמדה לפי `data-ref` של השורה. קטע בלי מיקום בטוח: עמעום עדין של שולי הדף + "מיקום משוער".
- שכבת הטקסט של ה-PDF אינה מוגשת. ה-PDF המלא אינו עולה לשום מקום.
- הגשה בייצור: R2 (`leokmei-tzura`, נתיבים `sukkah/002a.v.webp`) + נתיבי `/tz/*` ב-Worker. העלאת התמונות: `tools/tzura/upload_r2.sh` (wrangler מחובר).
- בדיקה מקומית: `uv run python tools/serve.py --port 8741` (מגיש גם `/tzimg/`).
