# החוקר - מערכת הבקרה הפנימית הקבועה

הוקם 26.11.2026 לבקשת מיכאל, לארבעת האתרים (לאוקמי גירסא, ממלכת הזוהר, נ"ך המפורש, שפע יואל).
המטרה: שמיכאל לא יגלה עוד תקלות אחת אחת. החוקר מגלה אותן לפני, מתקן מה שוודאי, וזוכר כל ממצא לתמיד.

## שני חלקים
א. **ההליכה** (מכנית, בלי טוקנים, GitHub Actions כל לילה ב-04:15): `walk.py` עובר כמו גולש על כל מסכת (שישה חלקים במקביל) ועל שאר האתרים, בחמישה גדלי מסך, בתצוגת זרימה וספר, לוחץ על כל כפתור, ומדפיס כל פרק בכל פרופיל (A4, B5, חוברת). בכל מסך רץ `probe.js` (בודק הכללים). `ledger.py` ממזג ליומן הקבוע `data/chokker/findings.json`, ו-`sheets.py` בונה גיליונות מגע של המסכים שהשתנו.
ב. **המוח** (משימת ענן כל בוקר, `NIGHT.md`): ממיין, מסתכל בעיניים על הגיליונות, מתקן ודאי ובודק שוב באתר החי, ממציא כל לילה בדיקות חדשות (השובר), משפר יזום, ושולח הודעה יומית קצרה רק עם שאלות אמיתיות.

## קבצים
- `invariants.json` - קטלוג הכללים (מכני/מבט/בינה/תהליך), כל כלל עם מקורו בהכרעות מיכאל. גדל כל לילה, לא נמחק.
- `probe.js` - הבדיקות שבתוך הדף. `walk.py` - ההליכה. `merge.py` - איחוד החלקים. `ledger.py` - היומן. `sheets.py` - גיליונות. `note.py` - רישום ידני.
- `data/chokker/findings.json` - כל ממצא לתמיד: פתוח, תוקן, אומת, חזר (נסיגה), לבעלים, הוכרע, כוזב.
- `data/chokker/runs/<תאריך>/` - סיכום, סטטיסטיקה, ההודעה. ענף `chokker-sheets` - הגיליונות של הלילה האחרון.

## הרצה ידנית
`python tools/chokker/walk.py --site leokmei --only bava-batra` ואז `python tools/chokker/ledger.py data/chokker/runs/<תאריך>`.
